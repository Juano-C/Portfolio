# Portfolio — Juan Chauvet

Portfolio estático multilingüe en español, inglés y portugués brasileño.

## Archivos
- `index.html`: español
- `index-en.html`: inglés
- `index-pt.html`: portugués brasileño
- `styles.css`: estilos compartidos
- `images/`: capturas reales de GameVault, SocialTree, Idle Forge Universe y la página de Valorant

## Abrir localmente
Abrí `index.html` en el navegador. El selector de idioma de la barra de navegación permite cambiar entre las tres versiones.

El diseño utiliza Bootstrap 5.3.3, Bootstrap Icons y Google Fonts desde CDN, por lo que esos recursos necesitan conexión a Internet para cargarse.

## Publicar en GitHub Pages
Subí el contenido de esta carpeta al repositorio del portfolio y habilitá GitHub Pages desde la configuración del repositorio. Mantené los tres HTML, `styles.css` y la carpeta `images` en sus rutas relativas actuales.

## Imágenes
Las capturas de proyectos se guardan localmente en `images/`. GameVault muestra la biblioteca sincronizada; SocialTree, la página principal; Idle Forge Universe, una partida en desarrollo; y Valorant, una sección de la página estática.


### Ampliar capturas
Las capturas de la sección de proyectos se pueden pulsar para abrir una vista ampliada. Se cierra con el botón X, haciendo clic en el fondo oscuro o pulsando Escape. La funcionalidad está implementada en `lightbox.js` y no requiere dependencias adicionales.
